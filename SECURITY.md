# Security policy

This repository is intentionally public and must contain only sanitized
coordination metadata.

## Report a security or privacy problem

Use GitHub's private vulnerability reporting for this repository when available.
Do not open a public Issue containing credentials, tokens, private logs,
personal data, private prompts, or unredacted production evidence.

If private vulnerability reporting is unavailable, contact the repository owner
through an existing private channel and provide only the minimum detail needed
to establish the problem.

## Accidental exposure

If sensitive material is discovered here, stop propagation, revoke or rotate
affected credentials where applicable, remove the material from the current tree
and history using an appropriate secure process, and publish only a sanitized
incident summary.
