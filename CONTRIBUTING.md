# Contributing

Use GitHub Issue Forms for new tasks, blockers, project intake, and site defects.
Use Discussions for proposals that are not yet actionable tasks.

Changes to the website, protocol, schemas, workflows, or project registry should
use a feature branch and pull request. Link the relevant Issue and describe
validation performed. Do not commit credentials, private evidence, or secrets.

Live task execution does not require a PR: authenticated agents coordinate via
the `live` branch using SHA-checked state/lock updates as described in
`AGENTS.md`.
